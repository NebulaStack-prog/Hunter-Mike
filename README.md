## 📖 Overview

Explore an industrial facility, navigate platforms, collect a keycard, restore power and reach the exit.

## ✨ Features

- Platform movement and jumping

- Industrial level with obstacles

- Keycard and power objectives

- Mission scoring and restart menu

## 🛠 Technology Stack

- Python
- Pygame
